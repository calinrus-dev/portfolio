## Cómo construyo

- **Decisiones con evidencia.** Formular una hipótesis, medir el recorrido real, comparar y conservar lo que mejora el resultado.
- **Datos cerca del trabajo.** Cuidar localidad de memoria, disposición de datos y alineación con las líneas de caché cuando la medición lo justifica; reducir copias, asignaciones y trabajo innecesario.
- **Control local.** Persistencia y recursos propios cuando aportan continuidad. Las dependencias externas deben tener una razón y un coste visible.
- **Densidad con claridad.** En escritorio, aprovechar el espacio con jerarquía y navegación rápida. En móvil, adaptar el recorrido al contexto y al tacto.
- **Accesibilidad desde el principio.** Contraste, escalado, teclado, foco visible y movimiento reducido forman parte de las decisiones de producto.

## Cómo leer este portfolio

Cada repositorio es un caso de estudio con componentes, decisiones, material visual y estado explícito. Hay prototipos, entregas documentadas y exploraciones históricas. Las capturas reales están identificadas; las láminas conceptuales emplean contenido ficticio.

La implementación se mantiene en repositorios privados. Aquí comparto la intención de producto, la calidad del diseño y la evidencia que puede mostrarse públicamente.
